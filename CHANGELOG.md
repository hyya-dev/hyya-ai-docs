## 1.1.0 — Mac, August 2026

hYYa Cloud now runs inside the app, in its own workspace — no browser.

- Switch between hYYa Vault, which runs on your Mac, and hYYa Cloud without leaving the app. Cloud brings its own models and your Cloud conversation history.
- Sign in with a 6-digit code, right in the app.
- Talk to hYYa Cloud out loud and hear it answer. Voice is a hYYa Cloud feature — hYYa Vault has no voice.
- Ask hYYa Cloud for a picture and it makes one. Image generation is hYYa Cloud only — hYYa Vault does not make images.
- Cloud credits and Cloud Ultra can now be bought in the app through the App Store.
- hYYa Vault itself stays free and runs entirely on your Mac. It needs no account.

Also in this version:
- Long passages in Chinese, Japanese and other non-Latin scripts could be indexed the wrong way, so DataLens sometimes matched the wrong part of a document. This is fixed.
- Amounts written with a currency code such as SAR or AED now line up the same way in exported Word and Excel files, and riyal and rupee columns are stored as numbers so they can be totalled.
- Exported spreadsheets repeat their column headers on every printed page, and chart labels in exported slides show the same number of decimals as the data behind them.
- Exported slide decks finish with a coverage note when part of your request did not fit — it names what was left out instead of dropping it quietly.

## 1.0.3 — Mac, August 2026

Fixes for hYYa Cloud plan names.

- Messages about Cloud features no longer name a plan that has been retired.

## 1.0.2 — Mac, August 2026

Fixes for the home screen.

- The home screen now lines up with hYYa Cloud, so switching engines no longer shifts the layout.
- In a short window, the greeting makes room so the message box stays visible.
- Settings now opens with Control-comma as well as Command-comma.

## 1.0.1 — Mac, August 2026

Fixes for hYYa Cloud inside the app.

- Saving and exporting now work: export a chat, download an image, save a document, spreadsheet or presentation a chat made, save a take-off workbook, or export everything from Settings. Each now opens a Save panel instead of doing nothing.
- "Add to Apple Calendar" now saves the event.
- Choosing several files at once adds them in one batch.
- Confirmation prompts now appear, including Clear chat history in DataLens.
- Send Feedback now opens your mail app.
- Images and source links open inside the app, still signed in.
- Pinch to zoom works again for images, tables and PDFs.
- Signing out now signs the web view out too.
- A save that fails now tells you, instead of looking like it worked.
- A per-chat model setting that never took effect has been removed. The model you pick in Settings is the one that answers.
- Signing out now ends your session on hYYa Cloud's servers, not only on this Mac.
